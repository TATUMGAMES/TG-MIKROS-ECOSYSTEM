# MIKROS Analytics

MIKROS Analytics is Tatum Games' game analytics and player-intelligence platform.

It was built around a simple problem: Most analytics platforms can tell a developer what is happening inside that developer's own game.

MIKROS is designed to provide additional context by using an information-sharing and data-pooling ecosystem, allowing participating developers to understand their performance and users in relation to broader anonymized ecosystem data.

## Core Capabilities

MIKROS supports game developers with:

- event analytics;
- user behavior analysis;
- retention and churn intelligence;
- monetization analysis;
- player segmentation;
- platform and device intelligence;
- user-level scores;
- competitor and peer benchmarking;
- KPI comparisons;
- milestones based on comparative performance;
- AI-assisted interpretation;
- and actionable recommendations.

## Key Difference

The core difference is **context**.

A single-game dashboard can show a developer what happened.

MIKROS is designed to help answer:

- Is this result good or bad relative to comparable games?
- Which users are most valuable?
- Which segments behave differently?
- Where are we underperforming?
- Which changes deserve attention?
- What should we investigate next?

As of 2026, MIKROS Analytics has three subscription tiers:
