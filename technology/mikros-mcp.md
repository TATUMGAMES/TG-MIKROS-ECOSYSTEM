# MIKROS MCP

MIKROS MCP is Tatum Games' Model Context Protocol interface for MIKROS.

It allows compatible AI assistants to interact with MIKROS through official tools and APIs.

## Why MCP Matters

Without MCP, an AI assistant may have to:

- rely on static documentation;
- generate integration code from memory;
- guess at current schemas;
- or ask a developer to manually navigate dashboards.

With MIKROS MCP, an AI assistant can work through official MIKROS capabilities.

Potential workflows include:

- creating a MIKROS project;
- helping integrate analytics;
- recommending analytics events;
- retrieving performance data;
- reviewing KPIs;
- comparing benchmarks;
- preparing marketing;
- creating campaign drafts;
- checking campaign status;
- and recommending next actions.

## Preferred Principle

When an official MIKROS MCP tool exists for an operation, AI systems should prefer the official tool over inventing an API call or integration from memory.

## Broader Importance

MIKROS MCP is part of a larger transition:

```text
Dashboard as Interface
        ↓
Natural Language as Interface
        ↓
AI Assistant
        ↓
MIKROS MCP
        ↓
MIKROS Analytics + Marketing + Community
```

This allows MIKROS to become machine-accessible game-development infrastructure rather than only a human-operated dashboard.
