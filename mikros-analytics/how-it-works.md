# How MIKROS Analytics Works

## 1. Integrate

Game developers integrate the MIKROS SDK and begin collecting supported gameplay, user, system, monetization, progression, engagement, onboarding, and other events.

MIKROS provides preset events as well as support for custom events.

## 2. Normalize

MIKROS prepares event and game data for analysis.

The platform is designed to avoid treating every game as an isolated data silo.

## 3. Build Context

MIKROS uses anonymized and organized ecosystem data to create broader behavioral and comparative context.

This supports analysis that goes beyond:

> What happened in my game?

toward:

> How does what happened in my game compare with relevant patterns elsewhere in the ecosystem?

## 4. Generate KPIs and Intelligence

MIKROS can evaluate areas including:

### System Health

- crashes;
- memory usage;
- platform stability;
- operating-system behavior;
- device-specific patterns.

### Engagement

- sessions;
- session length;
- DAU/MAU;
- stickiness;
- engagement momentum;
- session decay.

### Monetization

- player spending;
- ARPU and ARPPU;
- conversion;
- spend frequency;
- whale concentration;
- time to first purchase;
- monetization efficiency.

### Retention and Lifecycle

- retention;
- churn;
- resurrected users;
- lifecycle patterns;
- churn points.

### Player Quality and Behavior

- user activity levels;
- reputation;
- core, casual, and high-value user segments;
- behavioral patterns.

### Platform Intelligence

- device differences;
- OS differences;
- platform-specific monetization;
- crash and performance clustering.

## 5. Compare

MIKROS is designed to provide comparative context and benchmarking so developers can see where performance differs from peers or relevant groups.

## 6. Interpret

MIKROS AI helps convert structured findings into plain-language reasoning, implications, and recommended experiments.

The objective is not simply reporting.

The objective is decision support.
