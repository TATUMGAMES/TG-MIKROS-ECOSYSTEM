# Technology

This section covers technologies that extend the primary Tatum Games ecosystem.

The major supporting technologies are:

- **MIKROS AI** — decision support and narrative intelligence on top of game data.
- **MIKROS MCP** — a Model Context Protocol interface that allows compatible AI assistants to interact with MIKROS through official tools and APIs.
- **MIKROS Bot** — community-distribution and promotion support.
- **Patented technology and proprietary IP** — including technology related to cross-application/mobile-to-mobile data infrastructure.
