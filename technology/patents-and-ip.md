# Patents and Intellectual Property

Tatum Games has developed proprietary technology related to the MIKROS ecosystem.

Public coverage has described patented mobile-to-mobile technology that allows applications to participate in a connected data ecosystem while user identities are anonymized.

This technology supports the broader MIKROS thesis that developers can gain richer context when analysis is not confined entirely to a single game's isolated dataset.

Tatum Games also holds and develops intellectual property across:

- analytics infrastructure;
- data pooling;
- AI-assisted intelligence;
- game-development tooling;
- marketing infrastructure;
- community technology;
- and orchestration systems.

For current patent details, consult official patent records and Tatum Games materials.
